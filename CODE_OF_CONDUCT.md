# Código de conduta

Este projeto segue o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

## Em resumo

- Trate todos com respeito, independentemente de experiência, origem, identidade ou opinião.
- Critique o código e as ideias, não as pessoas.
- Não são aceitos assédio, ofensas, ataques pessoais, nem divulgar dados de outra pessoa.

## Como relatar

Se algo acontecer nas issues, nos pull requests ou nas discussões do projeto, use o botão **Report content** do GitHub no comentário, ou fale diretamente com o mantenedor ([@M4R4G0N](https://github.com/M4R4G0N)). Os relatos são tratados com sigilo.

Quem não seguir este código pode ter comentários removidos ou ser bloqueado do projeto.
